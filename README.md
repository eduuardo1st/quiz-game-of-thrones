Um sistema interativo e imersivo desenvolvido para fãs de **Game of Thrones** descobrirem qual personagem da série mais se assemelha à sua personalidade. Este projeto foi desenvolvido como parte dos requisitos da disciplina de **Programação para Web**.

---

## 🚀 Sobre o Projeto

O **Quiz Game of Thrones** é uma aplicação web que utiliza lógica de programação e manipulação dinâmica de elementos para oferecer uma experiência de usuário fluida. Através de uma série de perguntas estratégicas, o sistema processa as respostas e retorna o personagem que melhor representa o perfil do usuário.

### Principais Objetivos:
- Aplicar conceitos de **Programação Orientada a Objetos (POO)** em JavaScript.
- Demonstrar proficiência em **Manipulação de DOM**.
- Criar uma interface responsiva e temática.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web padrão, sem a necessidade de frameworks externos, focando na pureza do código:

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização personalizada com foco na estética da série (utilizando Flexbox/Grid).
- **JavaScript (ES6+)**:
  - Lógica de pontuação.
  - Manipulação dinâmica do DOM para transição de perguntas.
  - Organização do código seguindo princípios de POO.

---

## 🎮 Como Funciona

1. O usuário inicia o quiz na tela principal.
2. Uma série de perguntas é apresentada, cada uma com múltiplas opções de resposta.
3. Cada resposta está vinculada a traços de personalidade de personagens icônicos (ex: Jon Snow, Daenerys Targaryen, Tyrion Lannister, Cersei Lannister, etc.).
4. Ao final, o sistema calcula a maior afinidade e exibe o resultado com uma breve descrição do personagem.
