## 🌟 Introdução

Bem-vindo ao **Quiz Game of Thrones**, um projeto interativo e imersivo desenvolvido para os fãs da aclamada série da HBO. Descubra qual personagem de Westeros mais se alinha com a sua personalidade através de um questionário dinâmico e envolvente. Este projeto foi criado como parte dos requisitos da disciplina de Programação para Web, demonstrando a aplicação prática de conceitos fundamentais de desenvolvimento front-end.

## 🚀 Sobre o Projeto

O **Quiz Game of Thrones** é uma aplicação web que utiliza HTML5, CSS3 e JavaScript puro (ES6+) para oferecer uma experiência de usuário fluida e responsiva. O sistema processa as respostas de uma série de perguntas estratégicas, cada uma vinculada a traços de personalidade de personagens icônicos, e retorna o personagem que melhor representa o perfil do usuário.

### Principais Funcionalidades:

*   **Questionário Dinâmico**: Perguntas e opções de resposta que se adaptam à interação do usuário.
*   **Lógica de Pontuação**: Sistema de pontuação que associa respostas a diferentes personagens.
*   **Interface Temática**: Design inspirado no universo de Game of Thrones, com foco na usabilidade e estética.
*   **Responsividade**: Experiência otimizada para diferentes tamanhos de tela.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com tecnologias web padrão, sem a necessidade de frameworks ou bibliotecas externas, priorizando a compreensão e aplicação dos fundamentos:

*   **HTML5**: Para a estruturação semântica do conteúdo da página.
*   **CSS3**: Para estilização e criação de um layout responsivo e visualmente atraente, utilizando Flexbox e Grid.
*   **JavaScript (ES6+)**: Implementação da lógica do quiz, manipulação do DOM para transições de perguntas e exibição de resultados, e organização do código seguindo princípios de Programação Orientada a Objetos (POO).

## 🎮 Como Funciona

1.  **Início do Quiz**: O usuário clica em `Iniciar Questionário` na tela principal.
2.  **Respostas**: Uma série de 10 perguntas é apresentada, cada uma com múltiplas opções de resposta. Cada escolha contribui para a pontuação de diferentes personagens.
3.  **Resultado**: Ao final do questionário, o sistema calcula a maior afinidade e exibe o personagem que mais se assemelha ao perfil do usuário, juntamente com uma breve descrição.

## 💻 Como Executar Localmente

Para rodar o projeto em sua máquina local, siga os passos abaixo:

1.  **Clone o repositório:**

    ```bash
    git clone https://github.com/eduuardo1st/quiz-game-of-thrones.git
    ```

2.  **Acesse a pasta do projeto:**

    ```bash
    cd quiz-game-of-thrones
    ```

3.  **Abra o arquivo principal:**

    Basta abrir o arquivo `index.html` em qualquer navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.).
